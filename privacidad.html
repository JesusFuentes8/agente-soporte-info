Política de Privacidad

Última actualización: Octubre 2026

1. Datos a los que accede

La aplicación accede exclusivamente a la hoja de cálculo específica de Google Sheets vinculada al proyecto. Solo lee el nombre del usuario y el comentario enviado en el formulario, y escribe la clasificación generada, el sentimiento detectado y la marca de procesamiento.

2. Uso de la información

El texto de las quejas se envía de forma directa a la API de Google Gemini únicamente para clasificarlo. La información resultante se almacena en la misma hoja de cálculo y no se guarda en ningún servidor externo ni base de datos secundaria.

3. Tratamiento de datos y terceros

Los datos no son transferidos, vendidos ni compartidos con fines publicitarios. La aplicación no accede a ningún otro archivo o carpeta del usuario en Google Drive.

4. Revocación de permisos

El usuario puede revocar el acceso concedido a la aplicación en cualquier momento ingresando a la configuración de seguridad de Google en: myaccount.google.com/permissions.

5. Cumplimiento de políticas de Google

El uso y transferencia de información recibida desde las APIs de Google por parte de esta aplicación se apega rigurosamente a la Google API Services User Data Policy, incluyendo los requisitos de uso limitado (Limited Use).
